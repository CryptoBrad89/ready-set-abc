# C2 Pop Press

Same Silk Thread skeleton as C: header, two-column hello, floating Lucy, SATPIN beads, silk path, picture plates, iris, mesh. The comic layer is a second press, not C1 and not the Stitch page chrome. Anton, cyan `#00b4d8`, magenta `#e91e8c`, yellow `#ffe14a`, spinning starburst, misregistered type, cloud balloon, BOOM / ZAP / WOW. Comic reference is `UX-FROM-STITCH.md` and `app/css/skins.css`. No Stitch export folder was in this checkout.

## Motion

- MeshGradient drifts at speed 1.1, 1.9 on celebration.
- Letters trickle in. A starburst spins behind the headline over 9s.
- Magenta halftone drifts. Cyan and magenta canvas dots wander.
- Play’s border beam runs. Taps squash, then a 650ms BOOM / ZAP / WOW burst.
- Lucy floats. Iris wipe between screens. Confetti on the bow.
- `prefers-reduced-motion` is an opt-out only.
